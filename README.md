# «Земля и право» — юридический ИИ-ассистент

## Актуальный этап: юридическая помощь в веб-чате

Основной интерфейс теперь **groundAndLaw**, без Telegram. Первый локальный прототип использует отдельный файловый MCP:

```bash
python -m venv .venv
.venv/bin/python -m pip install -r requirements-legal.txt
.venv/bin/python -m land_assistant web --demo
```

Откройте http://127.0.0.1:8080 (в Codespaces — приватный порт 8080). Введите «Каков порядок образования земельного участка?», заполните анкету и получите учебный ответ без источников. **Demo не вызывает LLM; его ответы служат демонстрации цепочки**; реальное MCP-соединение и чтение файлов выполняются. Пять федеральных актов загружены и постатейно сверены с согласованными эталонами на 21.10.2026; автообновление ещё не запущено. Для настоящей LLM и сведений о базе см. [инструкцию прототипа](docs/legal-prototype.md).

Дальнейшие разделы README описывают ранее реализованный Telegram-этап; его код сохранён, но он не является интерфейсом нового прогона.


Рабочая основа Telegram-ассистента по приложенному ТЗ: дела клиентов, геометрия участков, проверка структурированных ПЗЗ, документы DOCX, мониторинг публикаций, уведомления, справочник нормативных выдержек и адаптеры внешних API.

**Статус: версия для демонстрации и дальнейшего наполнения, не завершённая система со 100% покрытием ТЗ.** Действующие ПЗЗ, официальные границы и утверждённые формы заказчик ещё не предоставил. Внешние сервисы без ключей не подключены. Матрица реализации и оставшиеся работы: [docs/requirements.md](docs/requirements.md).

## Демонстрация без токенов и установки зависимостей

Требуется Python 3.11+. Приложение использует стандартную библиотеку.

```bash
DATA_DIR=data/demo python -m land_assistant demo
```

Будет создана отдельная учебная база, выполнены 8 проверок и сохранён ZIP `data/demo/case-1.zip`: отчёт DOCX, перечень документов DOCX, черновик обращения DOCX, SVG контура и JSON расчёта. При повторном запуске номер дела увеличивается. **Все нормативы, границы и документы-основания в этом примере синтетические. Кадастровый номер взят из ТЗ и не проверялся через НСПД.**

Интерактивная демонстрация того же меню, что в Telegram:

```bash
DATA_DIR=data/console python -m land_assistant console
```

Введите `/new`, заполните карточку, затем `/analyze 1`, `/docs 1`. Файлы сохраняются в `data/console/exports`. Консольный пользователь имеет ID 1; дела из отдельной demo-базы принадлежат ID 123456 и не видны ему.

## Запуск Telegram-бота

```bash
cp .env.example .env
# Заполните TELEGRAM_BOT_TOKEN и ALLOWED_TELEGRAM_IDS в .env.
# Для API задайте случайный ADMIN_API_TOKEN длиной >=32 символов.
set -a
. ./.env
set +a
python -m land_assistant init
python -m land_assistant bot
```

Пустой список разрешённых Telegram ID запрещает запуск. Бот принимает сообщения только от этих пользователей в личных чатах. Это сотрудники с правом редактирования собственных дел; администратор отдельно управляет нормативными данными. Мониторинг и доставка оповещений работают в фоновом потоке независимо от ввода и генерации изображений. Запускайте один экземпляр bot на токен и базу.

Основной интерфейс — кнопки. Команды и номера дел вводить не нужно:

- «Новый участок» → ФИО/адрес → кадастровый номер или «Пропустить» → назначение кнопкой → координаты или «Пропустить».
- «Мои дела» → выбор дела → «Анализ», «Документы», «НСПД», «Материалы НСПД», «Пояснение», «Концепция».
- «Изменить данные» → выбор поля → ввод значения; назначение, муниципалитет и проверка ограничений выбираются кнопками. Координаты можно вводить построчно `долгота широта`, без JSON.
- «Законодательство» → выбор акта → текст вопроса.
- «Концепция» → здание/интерьер → пожелания или «Пропустить» → фото/план либо «Создать без фото».
- На шагах доступны «Отмена» и возврат в меню. Списки дел, полей, муниципалитетов и материалов разбиты на страницы.

После обновления перезапустите процесс и нажмите «Мои дела» или «Помощь» в существующей клавиатуре, затем «Главное меню». Старые текстовые команды сохраняются для совместимости и локальной консоли, но не требуются в Telegram. Технический список:

- `/new` — пошаговый сбор основных данных; `/new {JSON}` — полная карточка.
- `/cases`, `/edit ID {JSON}` — просмотр и дополнение собственных дел.
- `/analyze ID`, `/docs ID` — анализ и пакет документов.
- `/law land_code вопрос` — поиск по проверенным выдержкам; другие коды: `town_code`, `civil_procedure`, `101-fz`, `217-fz`.
- `/nspd ID` — работа через https://nspd.gov.ru/urban-analyze: URL-кнопка, инструкция и GeoJSON-контура для загрузки сотрудником; затем бот принимает PDF/ссылку результата. Прямое подключение и автоматический правовой разбор не реализованы. `/explain ID` — пояснение LLM.
- `/nspd_import ID`, `/nspd_reports ID`, `/nspd_report НОМЕР` — приём результата в дело, список материалов и подготовка к проверке. PDF до 12 МБ, ссылки только на `nspd.gov.ru`; исходники входят в `/docs ID`.
- `/concept ID building пожелания` или `/concept ID interior пожелания` — затем фото/план PNG/JPEG либо `/generate` без изображения.
- `/alerts`, `/cancel`, `/help`.

Текст «анализ 1», «документы 1», «НСПД 1» также распознаётся. Произвольные юридические задачи за пределами меню не исполняются.

## Наполнение и администрирование

```bash
python -m land_assistant import municipality /path/to/municipality.json
python -m land_assistant import rule /path/to/verified-pzz.json
python -m land_assistant import legal-document /path/to/legal-excerpt.json
python -m land_assistant import source /path/to/source.json
python -m land_assistant case /path/to/case.json --owner 123456
python -m land_assistant analyze 1
python -m land_assistant documents 1 --output /tmp/case-1.zip
python -m land_assistant api
```

JSON-схемы и API описаны в [docs/data-and-api.md](docs/data-and-api.md). Примеры из `examples/` предназначены исключительно для демонстрации. Команда `init` создаёт названия Симферополя и района без вымышленных правил и границ. Сельские поселения и другие муниципалитеты добавляются импортом.

Проверенные ПЗЗ имеют срок подтверждённой актуальности, ссылку на источник, пункт документа и автора проверки. Непроверенные редакции не участвуют в расчётах. Изменение источника ПЗЗ деактивирует правила соответствующего муниципалитета до повторной проверки. Изменение нормативного акта деактивирует выдержки соответствующего вида.

Мониторинг зарегистрированных URL: HTML, текст, PDF с текстовым слоем. Для PDF установите `poppler-utils` (в Docker уже включён). Ссылки на документы включены в сравнение HTML. Для сканов требуется внешний OCR; приложение явно сохраняет ошибку извлечения. Обход сайтов всех муниципалитетов, автоматическое извлечение юридических норм и GIS-зон из произвольных PDF не реализованы.

## Docker

```bash
docker compose up --build -d
```

Общая постоянная база для бота и API; API опубликован только на `127.0.0.1:8080`. Для удалённого доступа нужен TLS reverse proxy. В Docker адрес `127.0.0.1` в URL локальной LLM означает сам контейнер: используйте доступное из контейнера имя сервиса. Конфигурацию через `.env` не коммитьте.

## Проверка

```bash
python -m unittest discover -s tests -v
```

Проверяются расчёты, нехватка данных, устаревшие редакции, изоляция дел, геометрия, формирование DOCX/ZIP, изменения источников и деактивация правил, поиск норм, Telegram-сценарий, авторизация API, защита URL и контракты интеграций. Тест API открывает локальный порт. Реальные LLM и файловый MCP проверены в веб-прогоне 21.10.2026; Telegram, НСПД, image API и Docker этим прогоном не проверялись.

## Границы юридического результата

Программа проверяет загруженные числовые параметры и основные ВРИ. Она не подтверждает полноту всех правовых ограничений, не вычисляет автоматически зону по юридически значимой карте, не выдаёт разрешение и не заменяет юриста или кадастрового инженера. Площадь по WGS84 приблизительная; SVG — рабочая визуализация, не утверждённая СРЗУ. Отступ задаётся как проверенный исходный параметр, а не вычисляется по отсутствующему контуру здания. DOCX — редактируемые рабочие проекты, а не полный комплект проектной документации. Изображение — архитектурная концепция; действительные места подключения сетей требуют технических условий и координат.

Обновление 22.10.2026: рабочий веб-чат учитывает предыдущие сообщения клиента и заполненные анкеты текущего чата. Ответы сопровождаются короткими правовыми основаниями с названиями актов и статьями. [Описание памяти и формата ответа](docs/chat-memory-and-legal-bases.md).

## Общая юридическая помощь

Веб-чат обрабатывает также неземельные вопросы права РФ через отдельный MCP с публичными материалами КонсультантПлюс. Поиск не получает личные данные и историю. Дата проверки материалов отображается под ответом; недоступные и неподтверждённые редакции не заменяются знаниями модели. Кеш хранится в `data/consultant-cache/` (настройка `CONSULTANT_CACHE_DIR`), без полных ежедневных копий в Git. [Проверка общей юридической помощи](docs/general-legal-evaluation.md).
