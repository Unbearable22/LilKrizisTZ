## Файлы и MCP

- laws/*.md — девять частей пяти актов; разделение по границам нормативных блоков под лимит MCP 1 МиБ.
- laws/manifest.json — внутренний реестр, редакции, идентификаторы эталонных редакций, хеши, срок проверки.
- changes.jsonl — журнал фактических изменений. Последняя сверка записана по одному событию на акт.
- demo_land.md в laws/ — отдельная учебная фикстура; в live не используется.
- import-report.json — исходный импорт и актуальное соответствие файлам; reference-audit-summary.json — текущая проверка; official-audit-summary.json — историческая частичная официальная сверка.

Файлы подключены к MCP напрямую; импорт в SQLite не требуется. Сведения об эталонах и сравнениях внутренние. Удаление показа источников в текущем веб-интерфейсе остаётся отдельной задачей плана.
