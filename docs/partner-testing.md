# Проверка партнёром

## Локальный запуск Windows после обновления

Распакуйте весь проект и запустите `start-web.bat` двойным щелчком. Загрузчик переносит приложение с сетевого пути в локальный каталог, подготавливает Python и зависимости, загружает голосовую модель в фоне и открывает браузер. Ключ остаётся в вашей `.env`; он не входит в Git.

Повторный запуск использует существующий сервер только при совпадении кода, нормативных файлов, настроек и режима. После обновления выбирается свободный порт для новой версии; старое окно сервера можно закрыть отдельно. Адрес берите из нового окна запуска или автоматически открытой страницы. Идентификатор версии в служебной проверке — хеш, исходные настройки и ключи не публикуются.

Если архив распакован не полностью, `.bat` сообщает об отсутствующих сценариях запуска. Файл `.env.example` содержит актуальные пояснения к моделям. Проверены Python-сценарий и повторное использование сервера под Linux; выполнение самого `.bat` на реальной Windows здесь недоступно.

## Временный веб-чат в Codespaces

Ссылка: https://vigilant-giggle-4qvgx7p96pw437pxv-8080.app.github.dev/

Порт 8080 открыт публично. Вход в GitHub не нужен; если GitHub показывает стартовую страницу предупреждения, нажмите переход к приложению. Запущен LIVE-режим с подключённой моделью и нормативными материалами. Ссылка доступна, пока Codespace работает; при его остановке или удалении приложение недоступно. Это временная демонстрация.

Примеры для проверки:

1. «У меня участок, власти хотят его забрать. Документов пока нет. Что делать?»
2. «Умерла бабушка, остались квартира и участок. Как принять наследство? Дату смерти точно не помню».
3. «Работодатель второй месяц не платит зарплату. Что можно сделать?»
4. В том же чате допишите известные обстоятельства; проверьте, учитывает ли ответ уточнения.
5. Создайте новый чат и убедитесь, что обстоятельства предыдущего туда не перенеслись.

Неизвестные сведения можно так и указать. Предварительный ответ и варианты «если» допустимы; недоступность нужных норм должна быть явно обозначена. Запросы используют баланс настроенного API. Одновременно обрабатываются два запроса. История хранится в браузере, на другом устройстве не появится автоматически.

Для обратной связи запишите вопрос, уточнения, полученный ответ/скриншот, ожидаемое поведение и примерное время. Для демонстрации используйте вымышленные персональные данные.

Чтобы закрыть публичный доступ:

```bash
gh codespace ports visibility 8080:private -c "$CODESPACE_NAME"
```

## Диктовка вопроса

Рядом с вводом сообщения есть микрофон. Нажмите, разрешите доступ к микрофону, продиктуйте вопрос и нажмите микрофон повторно для остановки. Максимум — две минуты. «Отменить» отменяет запись или вставку результата. Текст появится в поле: проверьте адреса, даты и номера, затем отправьте вопрос. Автоматической отправки нет.

Аудио передаётся нашему серверу по HTTPS и распознаётся локально Whisper small (CPU/int8), без аудио-API Tooken Club. Запись не сохраняется на диск или в историю. После отправки вопроса распознанный текст обрабатывается как обычный текст, включая передачу модели через Tooken Club. Время распознавания зависит от длины записи и нагрузки. Одновременно распознаётся одна запись.

## Дополнительные материалы

Для поддерживаемых юридических тем добавлен ограниченный проход по проверенным материалам при пробеле в нормативных основаниях. По налогам может использоваться официальное разъяснение ФНС, обозначенное как разъяснение, а не закон. Пример: «Хочу продать участок в Крыму за 30–35 млн рублей. Какие налоги и как оформить продажу? Срок владения пока не помню». Проверяйте, что ответ даёт условные варианты и не придумывает точную сумму налога. Охват ограничен подключёнными источниками; произвольные сайты не используются.


## Проверенные документы без поискового API — 2 ноября 2026

Обновление: подключён резервный публичный поиск новых нормативных документов КонсультантПлюс, когда каталога недостаточно. [Схема, границы и проверка запроса о паспорте](web-search-fallback.md). Это поиск без отдельного API-ключа, а не подключение всех официальных сайтов.

Поисковый провайдер и поисковый ключ не нужны. Подключены прямые оглавления актов КонсультантПлюс и ограниченное официальное разъяснение ФНС о продаже участка. Другие ведомства перечислены как планируемые в `knowledge/trusted_sources.json`, но пока не подключены. КонсультантПлюс — справочно-правовой издатель, а не официальный орган опубликования; это различие не скрывается.

Новые вопросы сначала используют проверенный локальный контекст/SQLite-индекс. Если нужных оснований нет, выполняется ограниченное чтение документов через MCP соответствующей юридической функции. Прочитанные страницы индексируются автоматически. После смены даты или истечения 24 часов запись не используется без повторной проверки. Полного обхода сайтов при запросе нет. Историческая редакция без подтверждения не подставляется.

Для отдельного ограниченного наполнения/обновления индекса из корня проекта:

```bash
python scripts/update_source_index.py --topic consumer --query "неисправный товар без чека"
python scripts/update_source_index.py --topic land --query "изъятие участка для дороги"
```

Каждый запуск ограничен бюджетом и не обращается к LLM. Команду можно запускать по расписанию средствами ОС; постоянно работающий планировщик в приложение пока не встроен. Запуски, завершившиеся ошибкой, не обновляют дату проверки. Индекс и небольшой журнал изменений расположены в `data/consultant-cache/`, игнорируются Git. Полные резервные снимки в репозиторий не добавляются.

В ответе показываются ссылки на реально прочитанные документы, тип материала, редакция при наличии и дата проверки. Ссылки сохраняются с ответом в этом браузере. Старым ответам ссылки задним числом не добавляются. При неудачном уточнении остаётся предыдущий проверенный ответ с прежними документами. Совпадение цитаты и дополнительная модельная проверка уменьшают риск неподтверждённых выводов, но не являются юридической экспертизой.

Лимит обработки остался 120 секунд. Генерация ответа по-прежнему использует настроенный платный LLM API; бесплатным является отсутствие отдельного поискового сервиса. Windows-запуск не требует дополнительного поискового сервера. Для обновлённых Python-зависимостей используйте обычный `start-web.bat` либо установку `requirements-legal.txt`.

Дополнительная смысловая проверка тоже обращается к платной модели. Её можно выбрать через `LLM_VERIFIER_MODEL`; пустое значение использует `LLM_MODEL`. Модель классификации по-прежнему задаётся через `LLM_CLASSIFIER_MODEL`. После изменения `.env` перезапустите веб-чат. Доступность ID модели проверяйте в своём API-кабинете. Таймаут или отказ проверки не выдаёт черновик за проверенный ответ.

`LLM_VERIFIER_REASONING_EFFORT` — необязательный параметр только для проверяющей модели. Оставьте пустым для режима провайдера по умолчанию. `low` был принят API для gpt-6-luna, но полный прогон не подтвердил улучшения стабильности; включать его как универсальное исправление не рекомендуется. [Последняя диагностика](verifier-latency-2026-11-02.md).

Стабильность полного цикла пока не подтверждена: живые прогоны выявили таймауты API и смысловые отказы. Перед передачей партнёру ознакомьтесь с [результатами и ограничениями](verified-source-evaluation-2026-11-02.md). Эта версия не запускалась на реальной Windows; проверки интерфейса выполнены в Chromium под Linux.
