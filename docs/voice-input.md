# Локальная диктовка

Утверждённый сценарий: микрофон → запись до двух минут → остановка → локальный Whisper → редактируемый текст → обычная отправка. Кнопки на стартовом экране и внутри чата. Отмена, ошибки разрешения, пустая запись, лимит 8 МиБ, лимит декодированной длительности и серверный таймаут 90 с обрабатываются явно. При переходе в другой чат результат отменяется. На новых устройствах требуется разрешение микрофона, доступ по HTTPS.

Реализация: faster-whisper 1.2.1, small, CPU/int8, отдельный Python 3.12-процесс на запрос. Модель загружается с локального диска; сетевые ключи и история процесса ему не передаются. Для декодирования используется PyAV, отдельный FFmpeg не нужен. Аудио передаётся дочернему процессу через stdin, затем освобождается; исходные записи не журналируются и не добавляются в IndexedDB. Временное хранение в памяти возможно до завершения процесса (не более 90 с); отмена в браузере предотвращает вставку текста, уже запущенное распознавание на сервере может завершиться в пределах таймаута.

## Воспроизведение установки

```bash
python3.12 -m venv .venv-speech
.venv/bin/python -m pip --python .venv-speech/bin/python install -r requirements-speech.txt
.venv-speech/bin/python -c "from huggingface_hub import snapshot_download; snapshot_download('Systran/faster-whisper-small', local_dir='data/speech-model', allow_patterns=['model.bin','config.json','tokenizer.json','vocabulary.txt'])"
```

Зависимости и модель остаются вне Git; для другого сервера установку необходимо повторить. Модель занимает примерно 462 МиБ. Качество кадастровых номеров и собственных имён не гарантируется — пользователь проверяет текст. Распознавание не списывает токены Tooken Club, но использует CPU и память хостинга.

Проверки: 132 Python-теста, 18 JS-тестов; браузерный tests/browser_voice.py — запись/остановка/вставка без автоотправки/отмена/отказ доступа/остановка микрофона. Реальный worker: тишина не становится текстом, слишком длинная декодированная запись отклоняется до загрузки модели.

Сквозной тест HTTP с синтетической русской речью: 200, 8,6 с. Фраза «У меня есть земельный участок. Власти хотят его забрать. Что мне делать?» распознана с ошибкой слова «земельный» → «немедлый»; остальная часть сохранена. Это не проверка качества на реальном голосе. Исправление текста перед отправкой необходимо, автоматическая отправка отсутствует.
