# Подключения

В этой поставке внешние вызовы не выполнялись: доступы не заданы. Контракты проверены с подставными ответами. Нельзя считать их интеграционным тестом провайдера.

## Telegram

Прямой HTTPS Bot API, long polling `getUpdates`, `sendMessage`, multipart `sendDocument`, `getFile` для фото/плана. Offset хранится в SQLite. Уведомления отправляются фоном и перед обработкой текущего запроса. Отправка имеет семантику повторной доставки при сбое между Telegram и записью `delivered_at`; абсолютная гарантия единственной доставки отсутствует. При перезапуске в такой ситуации возможно повторное сообщение. Ошибки внешнего API не печатают токен в журнал.

Официальная документация: https://core.telegram.org/bots/api и https://core.telegram.org/bots/faq . Для реального запуска нужно удалить webhook у бота, если он ранее использовался: webhook и long polling одновременно не работают. Библиотека сама не сбрасывает чужой webhook.

## LLM

`LLM_URL` — полный URL совместимого `/v1/chat/completions`; `LLM_MODEL`, `LLM_API_KEY`. Можно указать локальный сервер вместо облака. Формат запроса: `model`, `temperature: 0`, `messages`. Ожидается `choices[0].message.content`.

LLM поясняет готовый структурированный расчёт. Она не является источником норм, не выставляет итоговый статус и не изменяет карточку. ФИО и адрес не отправляются специально в payload пояснения; отдельные загруженные цитаты/пункты всё же могут содержать персональные данные, поэтому оператор должен контролировать наполнение. Системный промпт не гарантирует отсутствие галлюцинаций; авторитетным результатом остаются сохранённые checks/citations, а не свободное пояснение.

## НСПД

`NSPD_ADAPTER_URL` — разрешённый оператором сервер, принимающий POST:

```json
{"cadastre":"90:12:172201:102","coordinates":[[34.1,45.0],[34.1004,45.0],[34.1,45.0003]]}
```

Ответ — JSON со сведениями и источниками согласно реализованному адаптеру. Авторизация — `Bearer NSPD_API_KEY`. Адаптер в этой поставке не включает обход защиты, неофициальные cookie или предполагаемый закрытый endpoint НСПД. Без конфигурации возвращается статус `not_configured` и ссылка https://nspd.gov.ru/map . Данные адаптера возвращаются как непроверенные и не подтверждают ограничения автоматически.

## Концепции изображений

`IMAGE_API_URL`, `IMAGE_API_KEY`, `IMAGE_MODEL`. POST:

```json
{
  "model":"provider-specific-model",
  "prompt":"Параметры из расчёта, пожелания, данные коммуникаций",
  "size":"1024x1024",
  "response_format":"b64_json",
  "reference_image_base64":"optional JPEG/PNG base64"
}
```

Ожидается `{"data":[{"b64_json":"base64 PNG"}]}`. Поле `reference_image_base64` — контракт нашего адаптера, а не обещание совместимости со всеми image API. Для редактирования реального фото нужно реализовать соответствующий провайдеру proxy, например преобразование в multipart image-edit. Сервису генерации передаётся исходное фото/план и пожелания; оператор должен учесть условия провайдера. Без API бот объясняет невозможность генерации.

Перед запросом повторно выполняется анализ. При нехватке данных или конфликте генерация не начинается. Даже положительный предварительный результат не означает, что генератор обеспечит размеры, отступы или корректные точки сетей: для этого нужны геометрическая валидация результата, проектные инструменты и специалист.

## Эксплуатация

Секреты хранятся в окружении; `.env` исключён из Git. API и SQLite — в доверенном контуре. Не публикуйте административный API без TLS и внешней защиты. Файлы источников ограничены 12 МБ, фото — 8 МБ. Для PDF используется системный `pdftotext` с таймаутом; для сканов нужен отдельно настроенный OCR. Внешние URL источников ограничены публичным HTTPS; дополнительно рекомендуется egress allowlist официальных доменов на уровне сети.
