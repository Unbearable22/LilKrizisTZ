# Подключения

В этой поставке внешние вызовы не выполнялись: доступы не заданы. Контракты проверены с подставными ответами. Нельзя считать их интеграционным тестом провайдера.

## Telegram

Прямой HTTPS Bot API, long polling `getUpdates`, `sendMessage`, multipart `sendDocument`, `getFile` для фото/плана. Offset хранится в SQLite. Уведомления отправляются фоном и перед обработкой текущего запроса. Отправка имеет семантику повторной доставки при сбое между Telegram и записью `delivered_at`; абсолютная гарантия единственной доставки отсутствует. При перезапуске в такой ситуации возможно повторное сообщение. Ошибки внешнего API не печатают токен в журнал.

Официальная документация: https://core.telegram.org/bots/api и https://core.telegram.org/bots/faq . Для реального запуска нужно удалить webhook у бота, если он ранее использовался: webhook и long polling одновременно не работают. Библиотека сама не сбрасывает чужой webhook.

## LLM

`LLM_URL` — полный URL совместимого `/v1/chat/completions`; `LLM_MODEL`, `LLM_API_KEY`. Можно указать локальный сервер вместо облака. Формат запроса: `model`, `temperature: 0`, `messages`. Ожидается `choices[0].message.content`.

LLM поясняет готовый структурированный расчёт. Она не является источником норм, не выставляет итоговый статус и не изменяет карточку. ФИО и адрес не отправляются специально в payload пояснения; отдельные загруженные цитаты/пункты всё же могут содержать персональные данные, поэтому оператор должен контролировать наполнение. Системный промпт не гарантирует отсутствие галлюцинаций; авторитетным результатом остаются сохранённые checks/citations, а не свободное пояснение.

## НСПД — «Градостроительная проработка онлайн»

Основной сервис по уточнению заказчика от 19.10.2026: https://nspd.gov.ru/urban-analyze . Он используется для предварительной градостроительной проработки участка/территории. Это веб-приложение; URL страницы нельзя подставлять в `NSPD_ADAPTER_URL` как JSON API.

В сообщении Управления Росреестра по Белгородской области от 12.10.2026 описаны вход через подтверждённую учётную запись Госуслуг, поиск по номеру/адресу, загрузка контура (в том числе GeoJSON), сохранение результата документом или ссылкой:
https://kartgeocentre.ru/produkty-i-uslugi/v-regionalnom-rosreestre-rasskazali-o-servise-gradostroitelnaja-prorabotka-onlajn-realizovannom-na-portale-nspd .

### Доступный сценарий первой версии

1. Сотрудник создаёт дело и вводит кадастровый номер и/или координаты WGS84.
2. Команда `/nspd ID` показывает URL-кнопку сервиса, номер и инструкцию; при наличии координат бот прикладывает GeoJSON замкнутого контура. Файл содержит только геометрию, без ФИО и адреса клиента. Это пользовательский контур, не подтверждение официальных границ.
3. Сотрудник самостоятельно входит на портал, выбирает участок/загружает контур, выполняет проработку и сохраняет доступный результат. Пароли, коды ЕСИА и cookies в боте не хранятся.
4. Специалист сопоставляет результат с участком, проверяет дату, источники, зоны и ограничения; отдельно проверяет действующие ПЗЗ. Отсутствие слоя/сведений не означает отсутствие ограничения.
5. Проверенные сведения вносятся в карточку через `/edit` или административный API с указанием основания в `nspd_evidence`. Приём материалов описан ниже; автоматическое юридическое извлечение ограничений и подтверждение их применимости не выполняются.

Открытие сервиса из среды разработки завершилось ошибкой доступа. Работа в личном кабинете, покрытие Крыма, доступные форматы/стоимость конкретного результата и наличие поддерживаемого программного интерфейса не подтверждены. Нужен один реальный результат из сервиса для проверки извлечения текста и последующей разработки структурированного разбора ограничений.

### Приём результата в Telegram

- `/nspd ID` открывает сервис URL-кнопкой и переводит диалог в режим приёма результата. Никакая форма входа Госуслуг в боте не создаётся.
- `/nspd_import ID` включает приём без повторного открытия сервиса.
- Отправьте PDF документом до 12 МБ или HTTPS-ссылку на `nspd.gov.ru`. Другие домены, ссылки с паролями/явными токенами и фотографии отчёта не принимаются. Ссылки только сохраняются: сервер их не открывает.
- Оригинальный PDF сохраняется в `DATA_DIR/nspd_reports/ID/` с SHA-256 в имени, без использования присланного имени файла как пути. Повторный материал в одном деле не дублируется. Происхождение файла не подтверждается одним фактом загрузки.
- При наличии `pdftotext` извлекается текст; при ошибке/отсутствии программы сохраняется оригинал и статус ручной проверки. OCR сканов не выполняется. Распознанные кадастровые номера сравниваются с текущим номером дела; совпадение не подтверждает полноту и применимость отчёта.
- `/nspd_reports ID` показывает сохранённые материалы; `/nspd_report НОМЕР` — дату получения, статус, начало извлечённого текста и перечень проверок для специалиста.
- `/docs ID` включает оригиналы PDF, метаданные и листы проверки в подпапку `nspd/` ZIP-пакета. Доступ к материалам проверяется по владельцу дела.
- `/cancel` отменяет ожидание файла/ссылки. Исходные сведения об ограничениях, `restrictions_checked`, `nspd_evidence` и нормативные правила автоматически не меняются. Внешним LLM материалы автоматически не отправляются.

Дата получения — время загрузки в бота, не дата формирования отчёта. Юридическая достоверность, подпись, актуальность и происхождение отчёта автоматически не проверяются. Лист подготовки — обзор для проверки специалистом, не юридическое заключение. Срок хранения материалов пока определяется оператором; исходники включайте в резервные копии базы.

### Будущая автоматизация

Документированный разрешённый интерфейс и способ авторизации нужно уточнить у оператора НСПД. До этого автоматический вход через ЕСИА, использование внутреннего API и прямой запрос по URL страницы не реализуются. Существующая настройка ниже предназначена только для отдельного реализованного адаптера; она не означает наличие прямой интеграции с сервисом.

`NSPD_ADAPTER_URL` — разрешённый оператором сервер, принимающий POST:

```json
{"cadastre":"90:12:172201:102","coordinates":[[34.1,45.0],[34.1004,45.0],[34.1,45.0003]]}
```

Ответ — JSON со сведениями и источниками согласно реализованному адаптеру. Авторизация — `Bearer NSPD_API_KEY`. Адаптер в этой поставке не включает обход защиты, неофициальные cookie или предполагаемый закрытый endpoint НСПД. Без конфигурации возвращается статус `manual_action_required`, ссылка https://nspd.gov.ru/urban-analyze и инструкция; при наличии контура — GeoJSON. Данные адаптера возвращаются как непроверенные и не подтверждают ограничения автоматически.

## Концепции изображений

`IMAGE_API_URL`, `IMAGE_API_KEY`, `IMAGE_MODEL`. POST:

```json
{
  "model":"provider-specific-model",
  "prompt":"Параметры из расчёта, пожелания, данные коммуникаций",
  "size":"1024x1024",
  "response_format":"b64_json",
  "reference_image_base64":"optional JPEG/PNG base64"
}
```

Ожидается `{"data":[{"b64_json":"base64 PNG"}]}`. Поле `reference_image_base64` — контракт нашего адаптера, а не обещание совместимости со всеми image API. Для редактирования реального фото нужно реализовать соответствующий провайдеру proxy, например преобразование в multipart image-edit. Сервису генерации передаётся исходное фото/план и пожелания; оператор должен учесть условия провайдера. Без API бот объясняет невозможность генерации.

Перед запросом повторно выполняется анализ. При нехватке данных или конфликте генерация не начинается. Даже положительный предварительный результат не означает, что генератор обеспечит размеры, отступы или корректные точки сетей: для этого нужны геометрическая валидация результата, проектные инструменты и специалист.

## Эксплуатация

Секреты хранятся в окружении; `.env` исключён из Git. API и SQLite — в доверенном контуре. Не публикуйте административный API без TLS и внешней защиты. Файлы источников ограничены 12 МБ, фото — 8 МБ. Для PDF используется системный `pdftotext` с таймаутом; для сканов нужен отдельно настроенный OCR. Внешние URL источников ограничены публичным HTTPS; дополнительно рекомендуется egress allowlist официальных доменов на уровне сети.
