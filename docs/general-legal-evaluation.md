# Общая юридическая помощь: проверка 22.10.2026

Реализованы две функции с отдельными настоящими stdio MCP: земельная помощь по локальным проверенным материалам и general_legal_help по публичному КонсультантПлюс. Новый источник не получает историю и личные данные: только закрытую каноническую юридическую поисковую формулировку, тему и дату. LLM получает исходный вопрос, историю и реально прочитанные нормы.

## Живые сценарии

Выполнены 10 разнообразных юридических запросов и неюридический контроль. Модель: deepseek-v4.1-flash через Tooken Club. Неполные вводные и тексты вопросов не исправлялись ради прохождения.

Повторный полный набор: **11/11 автоматических проверок**. По содержанию: 9 предварительных ответов на личные правовые ситуации, 1 уместное уточнение, 1 отказ по неюридической погоде. После него дополнительно улучшены поиск нормы об оплате подряда и раскрытие отсылок в семейном вопросе; адресные повторы history и family успешны. Последняя конфигурация не выдаётся за ещё один непрерывный прогон всей десятки.

Исходный диагностический запуск имел 2/11 автоматических прохождений и сохранён. Часть REVIEW означала не ошибку ответа, а устаревшую проверку упоминания сервиса в служебном ограничении. Были также реальные отказы из-за неподходящих норм и ошибки проверки ответа/обрыва генерации. В ходе разработки новые MCP-процессы получали уточнённый парсер; первоначальная серия — диагностическая, не замороженная версия для независимого бенчмарка.

## Выявленные причины и исправления

- Поиск без отраслевого контекста путал «брак» как семью и дефект товара, а взыскание займа — с уже идущим исполнительным производством. Запросы разделены по теме, добавлено ранжирование заголовков по редкости терминов; исполнительное производство выбирается только при соответствующем предмете.
- Из номера 146-ФЗ терялось окончание. Парсер сохраняет полный номер, включая 2300-1.
- Старый фильтр воспринимал «гарантия» как название ГАРАНТ. Границы слова исправлены в Python и JS; проверка кодексов расширена на неземельные отрасли.
- Лимита генерации 4096 не хватило одному смешанному ответу. Default ответа теперь 6144; классификатор по-прежнему 2048, сетевые таймауты не увеличены. Настройка LLM_ANSWER_TOKENS сохраняет приоритет.
- Пояснение об отсутствии связанных статей после одного переписывания ещё содержало непрочитанные номера. Публичное изложение в таком случае переводится в простое описание; проверенные акт/статья отображаются из legal_bases. Этот неуспешный адресный повтор family сохранён, после уточнения инструкции повтор прошёл.
- Отсылки распознаются также в формах «статьями/статьях», в пределах одного уровня и общего бюджета. Маркетинговая страница по URL статьи не становится нормативным фрагментом; заголовок статьи должен совпасть с кандидатом.

## Ограничения и ручная оценка

Проверены реальные фрагменты для наследства, труда, потребителей, семьи, найма жилья, займа и подряда. 13 корневых страниц доступны: [отчёт доступа](consultant-access.md). Это не полный доступ к коммерческой базе и не обещание ответа на любой юридический вопрос.

В смешанном запросе реально вызваны оба MCP: наследство на участок направлено в general_legal_help, строительство на нём — в legal_help; оба результата сохранены. Исправление факта «не трудовой договор, а подряд» направило вопрос в civil, без совета о зарплате.

Некоторые ответы охватывают только часть вопроса. Жилищный ответ не установил право на возврат залога; в истории подряда порядок неустойки и суда ограничен отсутствием нужных материалов. Семейные и иные отсылки могут не раскрыться полностью при сетевом бюджете. Не проверяются документы клиента, реестры, фактические сроки, права и судебные перспективы. Текущая публичная редакция не доказывает применимость к прошлому событию: неподтверждённый исторический запрос отклоняется. ГК, часть 3, принимается как текущий по явной метке издателя без выдумывания отсутствующей даты редакции.

В выбранных итоговых результатах нет технического error; первоначальные сбои и последующий неудачный семейный повтор не скрыты. Один ответ занял около 81 секунды. Чтение нормы/проверка ID не является независимой юридической экспертизой всех выводов модели. Повторы одного содержания между задачами остаются возможными.

## Воспроизведение

```bash
.venv/bin/python scripts/evaluate_legal.py --live \
  --cases examples/general-legal-evaluation.json \
  --output data/general-evaluation-next
```

Это явный запуск платных обращений к настроенной модели. Кеш, сырые HTML, исходные ответы и диагностика — вне Git. Первичный прогон: data/general-evaluation/initial; полный повтор: recheck; адресные: final-targeted, family-repaired; сопоставление: verification-report.json. Нет скрытых повторов до получения удачного результата.

## Финальная проверка кода

Независимый обзор обнаружил три существенных дефекта происхождения материалов. Исправлено: явная недействующая/отменённая редакция отвергается до проверки даты; ID включает хеш текста фрагмента, а разбиение на части не зависит от оставшегося бюджета; статья требует наблюдаемого нормативного заголовка `doc-style`, одного номера в обзоре недостаточно. Регрессионные тесты воспроизвели ошибки до исправления и прошли после. Новая проверка разметки принимает 99 сохранённых реальных страниц статей, без нового скачивания. Если источник изменит разметку, возвращается ошибка, а не предположительно нормативный текст.

Замечание о неясных ошибках смешанного запроса повышено до существенного: теперь указана краткая формулировка неразобранной задачи; прерванные общим таймаутом задачи также получают отдельный результат. Успешная часть сохраняется.

Решения при реализации: сохранили совместимость старого `parcel` с `individual`; кеш имеет резерв места под журнал; историческую применимость не выводим из текущей страницы; явную текущую редакцию без даты издателя обозначаем без придуманной даты; наружу передаём канонический юридический запрос вместо личных формулировок; лимит ответа по умолчанию 6144 токена, с сохранением пользовательской настройки. Цена этих решений — временный совместимый формат, ограниченная детализация поиска, отказ по неподтверждённым прошлым редакциям и больший возможный расход генерации. Полного покрытия коммерческой базы и экспертной проверки всех выводов нет.

Граничные стресс-тесты размера кеша и все варианты поведения внешнего сайта не исчерпаны. Это остаётся ограничением проверки; наблюдённые дефекты устранены. Локальные HTML, кеш и полные ответы в Git не добавляются. Изолированная рабочая копия сохраняется до явного решения о коммите, чтобы не потерять незакоммиченные изменения.

Итоговая локальная проверка после исправлений: **128 Python-тестов, 18 JavaScript-тестов**, браузерные сценарии общей помощи, памяти, сохранения ответа и земельного режима прошли. Живой набор выше выполнен до финальных исправлений происхождения; он не выдаётся за повторный полный прогон последней версии.

После переноса в основной проект выполнен сквозной LIVE-запрос через веб-API: наследство участка и квартиры, нет документов и неизвестна дата смерти. HTTP 200, partial_answer, 4 правовых основания, 43,31 с, дата проверки материалов сохранена. Это адресная проверка финальной версии, не ещё один полный набор. Веб-чат запущен на порту 8080.
