# Проверенные источники без поискового провайдера — 2 ноября 2026

Реализованы прямое обнаружение статей по оглавлениям КонсультантПлюс, ограниченный адаптер ФНС, SQLite FTS-индекс, загрузка через отдельные бизнес-MCP и сохранение кликабельных документов в чате. Другие ведомства пока не подключены. Поисковый API и отдельный поисковый сервис не нужны; генерация и смысловая проверка через Tooken Club остаются платными.

**Статус:** автоматические проверки пройдены; стабильность полного живого цикла не подтверждена. Базовый полный прогон дал **3 предварительных ответа и 4 технических ошибки из 7**. Последующий эксперимент с отдельным бюджетом reasoning дал 1/7; [продолжение диагностики](verifier-latency-2026-11-02.md) содержит новые результаты и исправление копирования ID. После него исправлена потеря уже одобренных разделов при повторной проверке; отдельный повтор указан ниже и не заменяет эту статистику.

## Реализованный цикл

Веб-чат → классификация задач → соответствующий бизнес-MCP → локальный проверенный индекс / ограниченное чтение разрешённых документов → короткий ответ → подбор дословных опор хостом → обязательная смысловая проверка моделью → проверка ID/цитат/структуры → ответ с документами.

- Проверяются HTTPS, точный домен/путь, публичность всех DNS-адресов и каждый редирект. Соединение привязано к проверенному IP с сохранением TLS-проверки имени. Пользовательские URL не загружаются; CAPTCHA и авторизация не обходятся.
- Земельный MCP реально загрузил 7 фрагментов из 4 документов по изъятию; общий MCP прочитал 7 потребительских фрагментов, включая права при недостатках и отсутствие чека. Истёкший локальный valid_until не продлевался.
- Индекс хранит происхождение, хеш, редакцию и дату проверки. Используется материал текущей московской даты не старше 24 часов. Ошибка обновления не делает старую запись свежей. Часть полного прогона использовала ранее проверенный в этот же день индекс: это не повторная сетевая загрузка каждой страницы при каждом вопросе.
- Поиск охватывает поддерживаемые темы, а не только продажу недвижимости. Для потребительского спора недостаточно одной статьи о сроках; для алиментов на ребёнка проверяется покрытие статей 80, 81 и 83. Поисковые формулировки закрытые, без передачи персональных данных на сайты источников.
- Неизвестные клиенту факты сами по себе не запускают повторную генерацию. Для неё нужны новые нормативные основания; одинаковый текст с разными кеш-ID новым основанием не считается.
- Все использованные основания включаются в ссылки. Ссылки, их дата и связь с разделами сохраняются в IndexedDB; ошибка уточнения сохраняет прежний успешный ответ с прежними документами. Старым чатам ссылки не выдумываются.

## Проверка ответа и исправления

Хост подбирает точные непрерывные цитаты для полного answer и каждого условного варианта. Модель проверки читает весь ответ, текущую задачу, исходный вопрос, сведения анкеты и нормативные фрагменты. Она проверяет смысл, условия и исключения; совпадение слов не доказывает вывод. Положительный вердикт не заменяет юридической экспертизы.

При отрицательном вердикте можно сохранить только неизменённые разделы, прямо одобренные проверкой, с отметкой неполноты. После последнего полного прогона такие полезные разделы возвращаются сразу, без риска потерять их на необязательной правке. Если одобренной полезной части нет, допускается одна содержательная правка и повторная проверка в оставшемся бюджете. Таймаут без положительного вердикта не разрешает показать черновик как проверенный.

Установленная отдельная причина HTTP 502: провайдер вернул `incomplete_upstream_stream` и сообщение об исчерпании лимита вывода. Проверочный бюджет 2048 токена был недостаточен; теперь используется настроенный LLM_ANSWER_TOKENS, по умолчанию 6144. Этот сбой отличается от обычной HTTP-ошибки. Исправление не устранило все задержки. Очередь, внутренний маршрут и скорость выполнения модели внутри провайдера по этим данным не устанавливаются.

LLM_VERIFIER_MODEL позволяет выбрать проверяющую модель отдельно; пустое значение использует LLM_MODEL. LLM_CLASSIFIER_MODEL по-прежнему задаёт классификатор. Все роли используют существующие URL/ключ. Общий предел — 120 секунд, классификация по умолчанию до 45, генерация до 60, отдельная проверка до 30 секунд внутри общего предела. Пределы не увеличивались ради успешного отчёта.

## Автоматические проверки

- Полный Python unittest: **183/183**, последний запуск после исправления сохранения одобренных разделов — 40,805 с.
- JavaScript: **20/20**.
- Два Chromium-сценария: безопасные ссылки, IndexedDB, неудачное уточнение, поля общей юридической помощи и сохранение прежней даты. Ответ API в браузерных сценариях подменён фикстурой: это проверка интерфейса, не живой юридический ответ. Первый повтор не открыл страницу из-за остановленного демонстрационного сервера; после его запуска оба сценария прошли.
- Регрессия потери одобренных частей сначала воспроизведена: ошибка вместо partial_answer при сбое необязательной правки. После исправления — 8/8 целевых pipeline-тестов; дополнительная проверка первого сохранённого земельного вердикта подтвердила допустимость трёх одобренных вариантов без нового API-вызова.
- Независимый обзор выявил четыре существенных дефекта: повтор генерации без новых материалов, пропуск ссылок на использованные основания, неполное потребительское покрытие и счётчик чтения ФНС. Все исправлены с RED→GREEN-тестами. Недоступный источник, историческая дата, пустой индекс и отсутствие подтверждённой PDF-редакции проверены автоматическими тестами.

## Решения, ограничения и обновление

- Работа выполнена в согласованном текущем checkout; несвязанный прежний отчёт сохранён без изменений.
- Источники подключаются только через подтверждённые интерфейсы. Реализованы разрешённые страницы КонсультантПлюс и конкретное разъяснение ФНС; прочие ведомства остаются disabled/planned. КонсультантПлюс — справочно-правовой издатель, не официальный орган опубликования. Приоритет Консультанта над Гарантом не отменяет юридическую силу официального акта.
- MCP сохраняет поля query/legal_topic/as_of_date; территория не проверяется автоматически. Региональные правила и произвольные правовые темы не обещаются покрытыми.
- Опоры привязаны к полным разделам. Механический подбор может пропустить значимую норму, поэтому обязательна смысловая проверка. Разделение генерации/проверки снижает дублирование вывода, но добавляет платный вызов и зависимость от API.
- PDF извлекается с ограничениями размера/страниц, но без проверенного адаптера редакции не допускается в основания; OCR не реализован.
- На реальной Windows версия не запускалась; Linux/Chromium не подтверждают отсутствие платформенных ошибок. Поисковый сервер Windows-запуску не нужен.
- Отложенное малое замечание обзора: полная очистка индекса при превышении 200 МиБ может сделать ID недоступным для параллельного чтения. Следствие — ошибка чтения, а не неподтверждённый ответ. Позднее нужна замена на безопасное вытеснение.
- Непроверенные юридические выводы не заменяются ответами модели по памяти. Надёжность ссылок и положительная модельная проверка не доказывают юридическую правильность; требуется содержательная экспертная приёмка.
