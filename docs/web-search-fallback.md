# Резервный поиск и исправление запроса о паспорте — 02.11.2026

Если локальных материалов недостаточно, оба бизнес-MCP могут искать новые документы через общедоступный поиск КонсультантПлюс. Поиск больше не ограничен заранее перечисленными законами. Отдельный поисковый API, ключ или поисковый сервер не требуются. LLM по-прежнему платная.

## Как обрабатывается нехватка оснований

1. Проверяется свежий тематический индекс, затем известные нормативные документы.
2. Если материалов нет либо исполнитель обозначил нормативный пробел, выполняется публичный поиск издателя с закрытой юридической формулировкой, без имени, адреса и других произвольных слов клиента.
3. Из выдачи берутся только открытые ссылки на документы. Сниппеты, рекламные блоки и ссылки на авторизованную систему не становятся основаниями.
4. Найденный документ действительно загружается через HTTPS с проверкой домена, публичного IP и редиректов. Проверяются нормативный текст и сведения о применимой редакции. Явная отметка издателя «последняя редакция» допускается как подтверждение текущего статуса, но не заменяется вымышленной датой редакции. Явные признаки отмены/архивной редакции имеют приоритет.
5. Прочитанные фрагменты поступают в модель. Ответ проходит обязательную смысловую проверку и проверку ссылок. В чате показываются действительно использованные документы.
6. Новые материалы сохраняются с темой, хешем и временем проверки для следующих обращений. Ошибка загрузки не делает их свежими.

При неполных фактах возможен условный ответ. При отсутствии нормативного подтверждения нельзя дописывать выводы по памяти модели. CAPTCHA, авторизация, 401/403/429 не обходятся. Поиск, который ещё не готов, или изменение разметки возвращают ограничение, а не выдуманный результат.

Сохранены общий предел 120 секунд, два поисковых действия, шесть новых загрузок, восемь чтений и 20 тысяч символов контекста. Начальный обход резервирует один корень и три загрузки для резервного поиска, нового корня и статьи. Исправлен найденный обзором дефект двойного списания поискового бюджета: последовательность «первоначальный поиск → дополнительный веб-поиск» проверяется с одним общим бюджетом.

## Границы доверия

Общий резервный поиск этой версии работает через КонсультантПлюс — справочно-правового издателя, а не официальный орган опубликования. Ранее подключённое разъяснение ФНС сохраняется. Другие официальные порталы, Гарант и популярные юридические сайты не объявляются подключёнными автоматически: для каждого нужны проверенный открытый интерфейс и адаптер чтения. Популярность и высокий ранг в выдаче не доказывают юридическую достоверность. Не подтверждённая историческая редакция не подменяется текущей.

Проверен публичный способ, используемый поисковой страницей самого издателя: GET /search/?q=... с XMLHttpRequest, JSON ready/results. Это не договорный API со SLA; при изменении публичного интерфейса адаптер может потребовать обновления. Неудачные пробы общих бесплатных поисковиков не включены: нерелевантная выдача и CAPTCHA не подходят для юридического ответа.

## Почему не отвечал запрос «У меня украли паспорт что делать»

В журнале сервера повторялись таймауты классификатора deepseek-v4.1-flash через 45 секунд, ещё до обращения к нормам. Проверенная проба gpt-6-luna разобрала точный вопрос за 5,87 секунды. Локальная .env переключена на gpt-6-luna для классификации, ответа и проверки; ключи не менялись и не публикуются. Это измеренный профиль для текущей проверки, не гарантия доступности провайдера по всем темам.

Добавлен актуальный источник: закон 138-ФЗ о гражданстве, включая статью 9 о паспорте. Известный паспортный запрос направляется к этой статье; статьи о прекращении гражданства и уведомлениях об иностранном гражданстве исключены из данного поиска и старого кеша. Нормы о паспортном положении без достаточных метаданных редакции не выдаются за проверенные текущие основания.

Первый полный повтор после смены классификатора получил таймаут проверки через 40,82 с: в старом кеше были нерелевантные статьи. После исправления отбора полный HTTP/MCP-прогон получил partial_answer за 67,51 с, три вызова модели. Это предварительная инструкция, а не полный перечень документов, пошлин и сроков восстановления.

Реальный Chromium без подмены API затем отправил тот же вопрос и получил partial_answer за **19,53 с**, одну публичную ссылку, без ошибок JavaScript. История сохранилась после перезагрузки, горизонтальной прокрутки при ширине 390 px нет. Это два отдельных наблюдения, не SLA. Неудачные попытки сохранены отдельно.

## Проверка интернет-поиска без каталога

Временный каталог roots=[] и пустой индекс; запрос «защита персональных данных». Первая попытка завершилась source_unavailable. Следующая независимая попытка нашла и прочитала три фрагмента ТК РФ о персональных данных работника:

- https://www.consultant.ru/document/cons_doc_LAW_34683/01f6157ff985b3cbbb50eb88fa6e26f30202532a/
- https://www.consultant.ru/document/cons_doc_LAW_34683/dc0a9a9993940d29a8daafe8144d3454c11b92cc/
- https://www.consultant.ru/document/cons_doc_LAW_34683/c3be99092ba7b07c366a06164bb2b2b135873064/

Это подтверждает обнаружение документов за пределами каталога и их реальное чтение. Трудовые нормы не покрывают любой спор о персональных данных: применимость к конкретному человеку всё равно проверяется при подготовке ответа. Часть кандидатов не вошла в бюджет; универсальная полнота поиска не заявляется.

Полный завершающий прогон: **201 Python-тест и 20 JavaScript-тестов прошли**. Независимый обзор новой подсистемы поиска подтвердил дефект двойного списания бюджета и риск исчерпания загрузок до дополнительного поиска; оба воспроизведены тестами до исправления и затем устранены. Обзор не подтверждает юридическую правильность ответов или SLA внешних сервисов.

Сырые синтетические результаты, скриншоты и журналы находятся в игнорируемом data/passport-fix/. Рабочий сервер после изменения кода необходимо перезапустить. Размещение на Timeweb не выполнялось.
