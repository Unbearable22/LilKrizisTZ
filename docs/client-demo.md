# Демонстрация юридической помощи

Подготовлен локальный веб-прототип. Публичный сервер и доступ заказчика по ссылке не развёрнуты. Для показа запустите приложение на своём компьютере и используйте демонстрацию экрана либо приватный доступ к среде разработки.

## Запуск

Из корня распакованного проекта:

```bash
python -m venv .venv
.venv/bin/python -m pip install -r requirements-legal.txt
cp .env.example .env
```

В локальном `.env` заполните `LLM_URL=https://tooken.club/v1/chat/completions`, `LLM_MODEL=deepseek-v4.1-flash` и собственный `LLM_API_KEY`. Ключ не отправляйте клиенту и не загружайте в GitHub. Если `.env` уже настроен, не перезаписывайте его.

```bash
set -a
source .env
set +a
.venv/bin/python -m land_assistant web
```

Откройте http://127.0.0.1:8080. В Codespaces используйте приватный порт 8080. Приложение проверяет адрес и Origin; произвольный публичный домен потребует отдельной настройки и авторизации.

Без ключа можно показать интерфейс командой `.venv/bin/python -m land_assistant web --demo`. В этом режиме ответы учебные; реальные вызовы модели не выполняются. В обоих режимах работает отдельный файловый MCP.

## Сценарий показа

1. Спросите: «Какими способами образуются земельные участки?» — понятная общая задача обрабатывается сразу, без анкеты.
2. Спросите: «Можно ли построить жилой дом на моём участке? Разрешённое использование не знаю».
3. Прочитайте предварительный разбор и варианты «если…, то…». Это не подтверждение допустимости строительства именно на участке.
4. Если под ответом есть уточнения, заполните только известное поле и нажмите «Уточнить ответ». Остальные поля можно оставить пустыми. Явное «не знаю» не блокирует ответ и не должно повторно запрашиваться в анкете.
5. Отправьте неопределённое «Помогите» — система попросит описать задачу. При отсутствии нормативных оснований объяснит ограничение, а не придумает вариант.
6. Обновите страницу и откройте сохранённый диалог.

Подробности изменения поведения: [conditional-answers.md](conditional-answers.md).

## Границы этапа

Подключена одна функция юридической помощи. Поиск локальный лексический: даже при наличии полного текста нужный фрагмент может не попасть в контекст; тогда система должна сообщить о недостаточности сведений. Проверка структуры и внутренних идентификаторов не доказывает юридическую правильность каждого вывода. Перед рабочей эксплуатацией нужна приёмка юристом на вопросах заказчика.

Пять актов повторно сверены по согласованным эталонам на 22.10.2026, изменений текста не найдено. Срок подтверждённой актуальности в реестре — **до конца 22.10.2026 по Москве**. После истечения документы исключаются из live-ответов. Автообновление ещё не реализовано; продлевать дату без повторной проверки нельзя.

НСПД, Госуслуги, официальные документы, подача заявлений и автоматический анализ вложений не подключены. История хранится в браузере. Для клиентского публичного сервера необходимы отдельное размещение и контроль доступа.

## Настройки после доработки качества

Необязательно: задайте `LLM_CLASSIFIER_MODEL`, чтобы классифицировать вопросы отдельной моделью. Пустое значение сохраняет `LLM_MODEL` для обоих этапов. После сравнения задержек проверен и включён профиль `deepseek-v4.1-flash` для обоих этапов. Pro доступен через настройки, но в замерах отвечал заметно дольше; детали в llm-timeouts.md.

`LLM_CLASSIFY_TIMEOUT=45` и `LLM_ANSWER_TIMEOUT=60` задают таймауты сетевого обращения. `LLM_ANSWER_TOKENS=4096` — верхний бюджет генерации ответа, включая рассуждение модели; он нужен для структурированных условных вариантов. Общая цепочка ограничена 120 секундами. После сетевого сбоя платный запрос автоматически не повторяется. Одна дополнительная генерация допускается только для устранения реквизитов из готового ответа; результат снова проверяется.

Повторная оценка запускается командой `.venv/bin/python scripts/evaluate_legal.py --live --output data/quality-stage/operator-run`. Это платные обращения к настроенной модели. Прогон последовательный; после ограничения частоты провайдером оставшиеся сценарии помечаются как невыполненные. Приватные диагностические файлы из `data/` клиенту не передавайте.
