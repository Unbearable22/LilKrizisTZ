# Проверка версии 0.1.0

15.10.2026, Python 3.14.2, Linux.

`python -m unittest discover -s tests -v`: 14 тестов, все прошли. Интеграционный тест API выполнялся с разрешением открытия локального порта; обычная песочница блокировала socket. Приложению не нужны сторонние Python-пакеты.

Подтверждены: положительный расчёт на синтетических данных; обнаружение превышения высоты и процента застройки; остановка при нехватке/устаревании данных; запрет доступа к чужим делам; геометрические ошибки и непокрытие вогнутой границей; содержимое сгенерированных DOCX/ZIP; базовая и изменённая версии источника; очередь и отсутствие повторной постановки той же версии; деактивация правил и выдержек при изменении; Telegram-сценарий с подставленной отправкой; нормативный поиск; контракты трёх адаптеров; авторизация HTTP и выгрузка документов; блокировка локальных URL источников.

Также выполнены компиляция модулей и локальный CLI demo с генерацией документов. Сборка клиентского архива выполняется `python scripts/build_handoff.py`.

Не проверены: реальная доставка Telegram, вызовы LLM/image API, НСПД, сайты муниципалитетов, обработка реальных PDF через poppler (в среде разработки `pdftotext` отсутствует), Docker-сборка, нагрузка, юридическая корректность ненаполненной базы. Автотесты адаптеров используют подставные ответы и этого не заменяют.
