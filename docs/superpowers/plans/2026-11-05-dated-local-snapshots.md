# Локальные нормативные снимки с датой проверки

Требование пользователя: истечение срока повторной проверки не исключает
локальный закон; показывать дату, на которую он проверен. valid_until —
технический срок сверки, а не прекращение действия закона.

- [x] Тесты: просроченный проверенный файл читается с датой; demo в live,
  будущая применимость, изменённый хеш и недопустимые пути по-прежнему блокируются.
- [x] Метаданные snapshot_as_of и last_checked_at проходят через реальный MCP;
  мастер-промпт и проверяющая модель знают, что обновления не подтверждены.
- [x] В ответе, основанном на таком снимке, обязательная серверная пометка даты,
  partial_answer и маркировка источника. Дата берётся из сохранённых метаданных,
  не заменяется сегодняшней; исходные manifest и тексты не изменяются.
- [x] Метка сохраняется в браузерной истории и при неудачном уточнении. Свежие
  сетевые материалы и политика их TTL не меняются.
- [x] Регрессии, живой запрос с локальной копией, обзор и локальный перезапуск.

Обзор выявил попадание даты прочитанного, но не использованного снимка в
свежий ответ, в том числе после бюджетного отсечения. Обе регрессии
воспроизведены падающими тестами и исправлены: уведомления контекста
фильтруются до отсечения, итоговая дата и пометка зависят от использованных
источников.

Живой прогон `data/dated-snapshot-live-2026-11-05/`: справка о схеме
расположения участка — содержательный partial_answer за 20,63 с с датой
22.10.2026. Браузерный сценарий проверил дату источника без выдуманного
времени и сохранение после перезагрузки. Содержимое законов и даты реестра
не изменялись; повторная правовая сверка на 05.11.2026 не заявляется.

Дополнительное требование пользователя: всегда запускать для локальной
сети. Сервер слушает 0.0.0.0, разрешает Host фактического локального IP
соединения, сохраняет проверку Origin. Две регрессии проверяют привязку
и отклонение посторонних Host. В Codespaces используется проброс порта.

Итоговая проверка: 233 Python-теста и 23 JavaScript-теста проходят.
После перезапуска LIVE проверены HTTP 200 по loopback, сетевому IP
контейнера и публичному адресу Codespaces. Timeweb не включался.
