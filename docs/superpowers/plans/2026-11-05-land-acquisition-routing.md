# Исправление поиска по приобретению неоформленного участка

Воспроизведение двух сообщений клиента: первый ответ general_guidance, второй
мог получить ограниченный проверенный ответ по нерелевантному для процедуры
набору. В контекст попадали регистрация, ВРИ и подтверждение имеющихся прав.
Локальный manifest истёк 22 октября; его даты не менять без новой сверки.

- [x] Тесты: бытовые формулировки приобретения пустого участка ведут к
  предоставлению/образованию; покупка у известного частного собственника и
  продажа своего участка не перехватываются.
- [x] Один общий распознаватель поискового намерения; канонический запрос без
  адресов/персональных данных. Классификатору указать сохранять условность
  публичной собственности и не дробить шаги одной цели на разные задачи.
- [x] Приоритет статей ЗК 39.3, 39.14, 39.15, 11.10 из проверяемого каталога;
  не принимать посторонние статьи из кеша как полное покрытие. При известном
  маршруте использовать бюджет на статьи каталога и читать их до веб-расширения.
- [x] Ограничить доминирование длинной статьи в контексте, сохраняя целые
  абзацы и явную частичность. Не обещать покупку без торгов или свободный статус.
- [x] Полные регрессии, живой повтор исходного диалога, обзор, документация,
  локальный перезапуск. Timeweb не включать.

Итог реализации: подбор исправлен, 9 новых регрессий; живой первый вопрос
получил полезную проверенную часть. Повтор продолжения после последней правки
снова general_guidance из-за отказа проверяющей модели. Устойчивость правового
ответа не достигнута и вынесена в docs/llm-timeouts.md; результат не скрыт.
