# Ответ при сбое проверки: план реализации

Требование пользователя: отсутствие обоснования или таймаут не должны оставлять
распознанный юридический запрос без полезного общего ответа; проверка может
занимать дольше и не должна отвергать обычную подготовительную рекомендацию.

Решение: сохранить проверку правовых выводов и сохранение подтверждённых частей.
При отсутствии проверенного результата в рабочем режиме вернуть статическую,
соответствующую теме общую ориентировку по подготовке фактов и материалов,
response_kind=general_guidance. Не выдавать её за подтверждённый правовой вывод,
не прикреплять к ней неприменённые нормы. Некорректный ввод, отмена, запрос вне
каталога не превращаются в юридический ответ. Ранее проверенный ответ в чате
сохраняется, если уточнение принесло только общую ориентировку.

- [x] Регрессионные тесты: отказ проверки, таймаут, пустой контекст, отмена,
  отсутствие непроверенного черновика/источников; сохранение предыдущего ответа.
- [x] Общая ориентировка в отдельном модуле; подключить к конечным веткам
  недостаточности оснований и ошибок после проверки входа. При сбое классификации — нейтральная общая подготовка без предположения о теме.
- [x] Проверка 60 с (параметр LLM_VERIFY_TIMEOUT, 5..90), общий бюджет 180 с,
  клиент 185 с, тестовый HTTP-клиент 190 с, nginx 200 с. Timeweb не включать.
- [x] Уточнить проверяющий промпт: подготовительные рекомендации не требуют
  отдельной нормы, правовые утверждения и существенные исключения проверяются.
- [x] Публичная маркировка, хранение истории, форма уточнения и браузерные проверки.
- [x] Все регрессии и живые повторы трёх неудачных вопросов; отдельно учитывать
  проверенные ответы и общие ориентировки. Обзор кода, документация, коммит.

Проверка: 215 Python, 22 JS; браузерная маркировка, ручной повтор и история.
Обзор кода выявил отсутствие кнопки повтора у новой ориентировки — исправлено
с воспроизведением в браузере. Остальные существенные замечания не найдены.
