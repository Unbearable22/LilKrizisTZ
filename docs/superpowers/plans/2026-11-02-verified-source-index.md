# Проверенные юридические документы без поискового провайдера — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Получать недостающие основания напрямую из разрешённых ресурсов и показывать проверяемые ссылки в веб-чате.

**Architecture:** Существующие бизнес-MCP используют общую библиотеку обнаружения, загрузки и индексации документов. SQLite хранит проверенные фрагменты; приложение-хост отвечает за бюджеты, связь выводов с основаниями и публичный ответ. Внешнего поискового провайдера нет.

**Tech Stack:** Python, SQLite FTS5, существующие MCP/httpx, JavaScript/IndexedDB. Для текстовых PDF — отдельная закреплённая зависимость pypdf после проверки совместимости.

**Spec:** ../specs/2026-11-02-verified-web-search-design.md

## Global Constraints

- Нет Brave, поискового API-ключа, SearXNG и нового обязательного сервиса; Tooken Club остаётся действующим платным LLM.
- Общий запрос: 120 секунд; до 2 запросов обнаружения, 10 кандидатов на запрос, 6 новых документов, 8 чтений суммарно, 20 тысяч символов контекста.
- HTML до 2 МиБ; PDF до 8 МиБ и 30 страниц; OCR не входит в реализацию.
- Раздельные MCP legal_help и general_legal_help; секреты и история не передаются источникам.
- Полный обход выполняется отдельно от пользовательского запроса. Истёкший материал не становится свежим без проверки.
- Никакого обхода авторизации, CAPTCHA, 401/403/429; никакого серверного размещения.
- Достаточные основания дают условный ответ даже при неполных фактах; отсутствие оснований обозначается явно.

## Review Focus

- Похожий домен, DNS-подмена или редирект на локальный адрес: соединение запрещено (задача 1).
- Обновление вернуло ошибку, старый документ есть: дата проверки не меняется (задача 2).
- Статья о сроках найдена, статья о правах отсутствует: не считать вопрос полностью обеспеченным (задачи 3–4).
- Несколько задач расходуют общий бюджет: проверенная первая часть сохраняется (задача 4).
- Уточнение завершилось ошибкой: прежний ответ остаётся со своими ссылками и датой (задача 5).

## Файлы и границы

Новые модули: `trusted_sources.py` — реестр и политика доступа; `trusted_http.py` — безопасная сеть; `source_index.py` — индекс; `source_discovery.py` — обнаружение; `source_documents.py` — извлечение; `answer_evidence.py` — проверка выводов. Не переносить весь pipeline в один новый модуль. Существующие парсеры Консультанта и ФНС переиспользовать после проверки требований.
