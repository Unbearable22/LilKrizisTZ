# Демонстрация клиенту

Показываем демонстрационную версию, не готовое юридическое заключение. Нормативы и границы в примере учебные. Никаких внешних платных запросов сценарий не выполняет.

1. Открыть `Демонстрация для клиента.docx` из пакета поставки: цель, функции и границы текущей версии.
2. Выполнить `DATA_DIR=data/demo python -m land_assistant demo`: на экране 8 проверок параметров со ссылкой на учебную редакцию.
3. Открыть `data/demo/case-1.zip`: отчёт, перечень, проект обращения, SVG участка. При повторном запуске имя ZIP содержит следующий номер.
4. Показать отрицательный сценарий: создать копию `examples/case.json`, изменить `height_m` на 30, импортировать через `DATA_DIR=data/demo python -m land_assistant case /path/to/copy.json --owner 123456`. Выполнить анализ по выведенному ID — программа обнаружит превышение.
5. Показать нехватку данных: `DATA_DIR=data/console python -m land_assistant console`, `/new`, заполнить ФИО/адрес/«нет»/`housing`/«нет», `/analyze 1` — вместо выдуманного разрешения список необходимых сведений.
6. Объяснить, что Telegram использует этот же обработчик. Реальный показ внутри Telegram возможен после создания бота и внесения ID сотрудников.
7. Уточнить первый муниципалитет и реальный обезличенный пример для следующей итерации. Записать правки по форме: шаг → ожидаемый результат → что изменить.

## Что можно проверить сейчас

Создание карточек, сохранение и редактирование; контроль контура; предварительную классификацию; вычисления по учебным ПЗЗ; отсутствие результата при нехватке сведений; формирование редактируемого пакета документов. Unit-тесты дополнительно воспроизводят смену источника, очередь уведомлений, изоляцию дел и работу адаптеров с имитацией ответов.

## Что не показывать как уже подключённое

Живые запросы НСПД, действующие ПЗЗ всех муниципалитетов, действующие нормы пяти законов, реальные Telegram-оповещения, ответы коммерческой/локальной LLM, генерируемые фото-концепции, официальную СРЗУ и комплект рабочей проектной документации. Эти возможности требуют данных, доступа и/или дальнейшей разработки, указанных в матрице.
