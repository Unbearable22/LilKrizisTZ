Доработка: обязательная полная анкета заменена предварительным ответом с условными вариантами и необязательными уточнениями. Понятный вопрос обрабатывается сразу. Источники остаются внутренними. Подробности: [conditional-answers.md](conditional-answers.md).

# Текущий этап — веб-прототип юридической помощи

Обновление 21.10.2026: по решению пользователя основной интерфейс — `groundAndLaw`, Telegram не целевой интерфейс нового прогона. Реализована локальная цепочка с отдельным MCP `legal_help`, .txt-промптом, поиском/чтением .md, начальной проверкой, единой анкетой, ответом без источников и явными demo/live. Инструкция: [docs/legal-prototype.md](legal-prototype.md).

В demo настоящий MCP работает без вызова LLM на синтетических материалах. Для реальных ответов нужны модель и проверенные нормативные документы. НСПД/ЕСИА, публичные аккаунты, полный юридический анализ и анализ вложений не входят в этот прототип. Ниже сохранена матрица исходного ТЗ и прежнего Telegram-этапа.

## Что запросить у клиента

1. Границу первой очереди: основной Telegram-сценарий или все этапы исходного ТЗ одновременно.
2. ПЗЗ и изменения с официальными URL, карты зон и границы муниципалитетов; сотрудника, который подтверждает актуальность и интерпретацию.
3. Примеры реальных дел с ожидаемым результатом, перечни процедур и официальные шаблоны документов.
4. Порядок доступа к НСПД/ЕГРН и ограничения использования сведений.
5. Telegram-бота и список ID сотрудников; ключи вводятся в окружение сервера, не в переписку и не в Git.
6. Выбор LLM и image API либо ресурсы для локальной модели; условия передачи данных провайдерам.
7. Для архитектуры — состав проектной документации, CAD/BIM, геометрические и инженерные требования, данные подключений сетей.
8. Сервер, домен, резервирование, ответственных за юридическую проверку и эксплуатацию.

## Предлагаемая приёмка первой очереди

На предоставленных заказчиком реальных обезличенных примерах: корректное определение муниципалитета; точное совпадение каждого числового ограничения с подтверждённым пунктом ПЗЗ; обязательная остановка при недостающих данных; правильная изоляция дел; проверенный состав документов; тестовое изменение зарегистрированного источника с получением уведомления и файла в Telegram; сверка результата юристом и кадастровым специалистом. Учебная демонстрация и unit-тесты эту приёмку не заменяют.

## Изменение 22.10.2026: контекст чата и законы в ответе

По подтверждённому решению пользователя прежнее требование скрывать все источники заменено показом правовых оснований: название акта, статья и короткое пояснение. Предыдущие сообщения клиента и анкеты текущего чата передаются обеим моделям; известные поля повторно не запрашиваются. Детали и ограничения: [память чата и правовые основания](chat-memory-and-legal-bases.md).
