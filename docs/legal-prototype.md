Новый порядок неполных данных: [conditional-answers.md](conditional-answers.md). Понятный вопрос не требует предварительного заполнения анкеты; уточнения после предварительного ответа необязательны. Прежние описания обязательной анкеты ниже относятся к ранней версии.

Текущий проверенный профиль — DeepSeek V4.1 Flash для обоих этапов. Сравнение задержек и результат20/20: [llm-timeouts.md](llm-timeouts.md).

# Первый прототип услуги «Юридическая помощь»

Версия для локальной проверки, 21.10.2026. Основной интерфейс — ваш веб-чат `groundAndLaw`; Telegram не нужен для этого запуска.

## Быстрый запуск без ключей

Из корня проекта:

```bash
python -m venv .venv
.venv/bin/python -m pip install -r requirements-legal.txt
.venv/bin/python -m land_assistant web --demo
```

Откройте **http://127.0.0.1:8080**. В Codespaces используйте вкладку «Порты» → порт 8080 → «Открыть в браузере»; сохраняйте видимость порта **Private**. Чтобы выбрать другой порт: `--port 8081`. Файлы нельзя просто открыть через `file://`: нужен сервер приложения. Если используете VS Code Live Server, остановите его для этого интерфейса и откройте именно порт Python-приложения.

Сервер слушает только loopback. Публичного входа, аккаунтов и серверной истории чатов пока нет. Не публикуйте порт без отдельного механизма доступа. История и вложения хранятся в IndexedDB текущего браузера; очистка данных сайта удаляет эту историю. Сервер её не резервирует.

## Что показать

1. Отправьте: «Каков порядок образования земельного участка?».
2. Заполните единую анкету: ситуация уже подставлена из исходного вопроса; укажите желаемый результат, например «Получить общую справку о порядке действий».
3. Нажмите «Передать сведения и выполнить».
4. Появится ответ; в рабочем режиме — с коротким блоком правовых оснований, без технической трассировки.
5. Для проверки ранней остановки отправьте: «Можно ли построить офис на моём участке?» — потребуется расширенная анкета по объекту; до её заполнения MCP не запускается.
6. Запрос вне подключённой функции, например о космических ракетах, возвращает явное ограничение, а не случайный алгоритм.

**Demo — не нейросетевой юридический ответ.** В нём настоящий MCP-клиент запускает отдельный MCP-сервер и реально читает `.txt`/`.md`; классификация и обзор фрагментов выполняются детерминированной учебной моделью, без API. В demo используется синтетическая фикстура; для live в поставке есть пять сверенных актов. `example.org` — демонстрационная ссылка, не источник закона. Баннер режима виден постоянно.

## Реальная модель

Задайте в `.env` полный OpenAI-совместимый endpoint и модель, при необходимости API-ключ:

```dotenv
LLM_URL=https://your-provider.example/v1/chat/completions
LLM_MODEL=your-model-name
LLM_API_KEY=
```

Это пример формы, не работающие реквизиты провайдера. Нужна поддержка `response_format: {"type":"json_object"}` и параметров chat completions. Для локальной модели можно указать локальный URL без ключа. Вызовы имеют таймаут; автоматических повторов платных запросов нет.

Затем:

```bash
set -a
source .env
set +a
.venv/bin/python -m land_assistant web
```

Без `--demo` используется только live. Если endpoint/модель отсутствуют, сервер не стартует с понятным сообщением; переключения на demo нет. Реальные вызовы DeepSeek V4 Pro через Tooken Club проверены 21.10.2026. Подробности прогона: docs/legal-evaluation.md.

**Учебные документы не используются в live.** На 21.10.2026 загружены пять полных актов, постатейно сверенных с «КонсультантПлюс» и дополнительно с «Гарантом». Проверка файлов действует до конца 21.10.2026; автообновление ещё не реализовано. Детали: `knowledge/reference-audit-summary.json`.

## Файлы MCP

- `knowledge/prompts/legal_help.txt` — один мастер-промпт одного алгоритма.
- `knowledge/laws/*.md` — нормативные материалы, разделённые заголовками статей/пунктов.
- `knowledge/laws/manifest.json` — ID, путь, название, редакция, ссылка, дата подтверждённой актуальности, проверяющий и `demo`.
- `knowledge/tasks.json` — описательный каталог; прототип разрешает только зафиксированный `legal_help`, динамическое добавление функций пока не реализовано.

Поля документа:

```json
{
  "id": "document-id",
  "path": "document-id.md",
  "title": "Название проверенного документа",
  "version": "Редакция",
  "source_url": "https://official-source.example/document",
  "effective_from": "2026-01-01",
  "valid_until": "2026-11-01",
  "verified_by": "Ответственный специалист",
  "demo": false
}
```

Пример не представляет реальный нормативный акт. `valid_until` — срок подтверждённой специалистом актуальности, а не выдуманный срок действия закона. Строки дат задаются YYYY-MM-DD; новые файлы требуют проверки источника и применимости. Лексический поиск не является полноценным юридическим поиском и может не найти нужное при другой формулировке. Форматы «ГП/ФЗ» не распознаются по имени файла: важны содержимое и корректные реквизиты.

Путь к другой базе: `--knowledge-root /absolute/path/to/knowledge`. MCP не принимает произвольные пути от модели; работает только на чтение. В MCP-процесс не передаются ключи LLM и полная история браузерных чатов. Классификатор и исполнитель получают текущий вопрос, анкету и предыдущие сообщения клиента из этого чата; исполнитель также получает найденные фрагменты. Подробности: [память чата и правовые основания](chat-memory-and-legal-bases.md).

## Что проверяет прототип

Вход: размер и форма сообщения/анкеты, Origin, число одновременных запросов. Далее: разрешённые функции и структура плана, полный список обязательных исходных данных, чтение источников MCP, допустимые ID и ссылки ответа. Реквизиты правовых оснований берутся только из реально прочитанных фрагментов; внутренние ID клиенту не передаются. Это не доказывает, что свободное пояснение юридически следует из них.

До анкеты выполняется только определение задачи. Реальные документы и дополнительные инструменты MCP запрашиваются после комплектования данных. Неизвестные права/категория/ВРИ не заменяются догадками. Адрес, кадастровые сведения, подлинность документов и юридическая допустимость действий в этой версии внешними сервисами не проверяются.

Вложения сохраняет исходный интерфейс, но в юридическую цепочку они пока не передаются. Отправка сообщения с вложением показывает явную ошибку; файл не считается прочитанным. Голосовые кнопки отключены. Данные анкеты передаются выбранному LLM-провайдеру в live: используйте только сведения, которые допустимо передавать этому провайдеру.

Отмена в браузере прекращает ожидание и защищает от позднего ответа в закрытом чате. Сервер обнаруживает разрыв соединения и отменяет дальнейшие асинхронные шаги MCP/LLM, освобождая слот. Уже принятое провайдером вычисление при этом может продолжаться на его стороне; возврат стоимости не гарантируется. Повтор запускается только явной кнопкой и в live может снова расходовать API-бюджет.
