# Запуск в Windows одной кнопкой

1. Скачайте актуальный проект и распакуйте архив целиком.
2. Перенесите ваш заполненный `.env` в корень рядом со `start-web.bat`. Если настроек ещё нет, при запуске откроется файл для заполнения LLM_URL, LLM_API_KEY и LLM_MODEL. Ключ не отправляйте в чат или GitHub.
3. Дважды нажмите `start-web.bat`. Он сам подготовит Python 3.12, зависимости и локальный Whisper, запустит чат и откроет страницу в браузере.

Python не требуется устанавливать вручную. Права администратора и изменение системного PATH не запрашиваются. Первый запуск требует доступа к GitHub, источникам пакетов и модели; он скачивает несколько сотен мегабайт и может занять несколько минут. При следующих запусках используется кеш.

Программа копируется в `%LOCALAPPDATA%\GroundAndLaw\<идентификатор>\app`, поэтому перенаправленный сетевой рабочий стол не используется для установки зависимостей. Настройки из `.env` исходной папки копируются в локальную рабочую копию; если их там нет, созданные локальные настройки сохраняются. При обновлении папки проекта запустите bat повторно. История браузера остаётся привязана к адресу/порту, поэтому при смене порта прежние чаты могут быть не видны.

Если 8080 занят другой программой, выбирается следующий доступный порт (до 20 вариантов); браузер открывает выбранный адрес. Если обнаружен уже запущенный веб-чат, открывается он. Окно консоли нужно оставлять открытым; Ctrl+C останавливает приложение.

Дополнительные параметры: `--demo` — учебный режим без API; `--no-speech` — не устанавливать Whisper; `--no-browser` — не открывать браузер; `--port 8081` — начать выбор порта с 8081. Обычно параметры не нужны.

Подготовка выполняется scripts/bootstrap_windows.ps1. Он скачивает фиксированный релиз uv 0.13.6 с официального GitHub astral-sh/uv, проверяет ZIP по опубликованному SHA-256 и через него подготавливает управляемый Python 3.12 в пользовательской папке. Установка системного Python не меняется. Основной запуск выполняет scripts/run_web.py.

Корпоративная политика может запретить запуск PowerShell/скачанных программ или сетевые загрузки. Скрипт не обходит такие политики; в этом случае нужна помощь IT. Ключ модели нужен для настоящих ответов, даже если подготовка окружения автоматическая.

Проверка: Python-тесты автоматического выбора порта, повторного использования сервера, разбора .env и путей; запуск Python-части возможен на Linux. PowerShell/CMD и полный первый запуск на чистом Windows в текущей среде недоступны, поэтому их работоспособность на конкретном компьютере должна быть подтверждена реальным запуском.

Проверки нового варианта: 142 Python-теста прошли; сценарий bootstrap разобран штатным парсером PowerShell 7 без синтаксических ошибок. Это не заменяет реальный запуск на Windows PowerShell 5.1 и корпоративном компьютере. При обновлении файлов завершите предыдущий сервер перед повторным запуском.

Проверка настроек теперь выполняется одной Python-функцией (`--check-config`), без отдельного разбора .env регулярным выражением PowerShell. При пустых значениях показываются только названия недостающих полей и путь к файлу, затем открывается редактор. Если .env есть в исходной папке проекта, редактируется он и результат копируется в рабочую папку, чтобы исправления не исчезали при следующем запуске. Токен Telegram не заменяет API-ключ LLM.
