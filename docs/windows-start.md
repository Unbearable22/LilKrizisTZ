# Запуск в Windows — 2 ноября 2026 года

1. Скачайте или клонируйте актуальный репозиторий и распакуйте его целиком. Не запускайте bat изнутри ZIP.
2. Установите Python 3.12 или 3.13. В установщике включите Add Python to PATH; затем откройте новое окно терминала, если оно уже было открыто.
3. Создайте `.env` из `.env.example`. Заполните LLM_URL, LLM_API_KEY, LLM_MODEL и при необходимости LLM_CLASSIFIER_MODEL. Существующий `.env` файл запуска не перезаписывает. Значения разбираются как данные, shell-команды из них не выполняются.
4. Откройте `start-web.bat` двойным щелчком. Первый запуск требует Интернета для зависимостей и модели. После подготовки браузер откроется автоматически.
5. Пользуйтесь чатом по адресу http://127.0.0.1:8080. Окно консоли оставьте открытым. Для остановки нажмите Ctrl+C.

Переключатели: `--demo` — без API модели; `--no-speech` — без подготовки Whisper; `--no-browser` — не открывать браузер; `--port 8081` — другой порт. Существующий рабочий чат на выбранном порту открывается без второго сервера. Если порт занят другим приложением, показывается ошибка.

`start-web.bat` выбирает Python 3.12/3.13, вызывает scripts/run_web.py, готовит .venv-web и устанавливает requirements-legal.txt/requirements-speech.txt. Диктовка использует тот же отдельный Python через SPEECH_PYTHON, что работает и с Windows-путями. При обновлении файлов requirements зависимости проверяются заново. При ошибке окно не исчезает сразу: причина видна в консоли.

Запуск проверен модульными тестами разбора .env/Windows-путей и логики сервиса. В текущей среде Linux нет cmd.exe, поэтому реальный двойной щелчок в Windows здесь не проверялся. Отдельно выполняется запуск Python-части в учебном режиме на Linux. Полные сценарии LLM и актуальность нормативной базы не доказываются проверкой bat-файла; при запросах модели используются обычные проверки источников приложения.

Это локальный запуск. Для постоянного адреса нужен отдельный сервер/размещение (например, Timeweb.cloud); создание bat не выполняет публикацию в хостинг.

Проверка 02.11.2026: запуск helper через Python 3.12 с подготовленным окружением и флагами --demo --no-speech --no-browser поднял сервер, config вернул HTTP 200 / demo; повторный вызов распознал уже работающий чат. Windows cmd.exe здесь отсутствует, поэтому проверка .bat ограничена анализом команд и переносимых Python-путей.


## Сетевая папка (UNC)

Если рабочий стол перенаправлен на сетевой ресурс вида `\\server\share\...`, обычный `cd` в CMD не поддерживает такой рабочий каталог. Исправленный start-web.bat использует `pushd`: CMD временно назначает сетевой папке букву диска. При завершении выполняется `popd`. Если папка недоступна, запуск останавливается до вызова Python и показывает отдельную ошибку.

Если организация запрещает назначение сетевого диска или установка зависимостей на сетевом ресурсе не проходит, распакуйте весь проект в локальную папку, например `C:\Projects\LilKrizisTZ`, перенесите туда свой `.env` и запустите bat оттуда. Не переносите уже созданные виртуальные окружения между каталогами: они должны создаваться заново.

Сообщение CMD о первоначальном UNC-каталоге может появиться ещё до исполнения bat. Важен дальнейший запуск после pushd: обращение к C:\Windows\scripts\run_web.py больше не должно происходить. Реального Windows/UNC окружения в текущей среде проверки нет.
