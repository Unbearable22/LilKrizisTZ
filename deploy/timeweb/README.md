# Timeweb: тестовый сервер

Размещение 2 ноября 2026 года: http://186.246.14.157/.
Ubuntu 24.04, 4 ГБ RAM. Это HTTP-стенд для проверки: HTTPS и домен пока
не подключены. Не передавайте чувствительные сведения до подключения HTTPS.
Голосовой ввод отключён (`SPEECH_DISABLED=1`); модель Whisper не переносилась.

## Структура сервера

- `/opt/groundandlaw/app`: код, интерфейс, knowledge, scripts, examples.
- `/opt/groundandlaw/venv`: Python 3.12, requirements-legal.txt.
- `/opt/groundandlaw/app/data`: постоянные данные и кеши.
- `/etc/groundandlaw.env`: конфигурация LLM, права 0600, владелец root.
  Systemd читает файл перед запуском приложения от пользователя groundandlaw.
  Telegram-токен не переносится. Значения секретов в репозитории отсутствуют.
- `/etc/systemd/system/groundandlaw.service`: непривилегированный процесс,
  автозапуск, перезапуск при сбое. Приложение слушает только 127.0.0.1:8080.
- nginx: внешний порт 80, ограничение юридических запросов 6/мин на IP,
  burst 3, таймаут ответа 150 секунд, журнал посещений отключён.

Нормативные MCP-процессы запускаются приложением через stdio.
История чатов остаётся в браузере пользователя, перенос кода её не переносит.
Обновление не должно удалять `data` или заменять файл конфигурации секретов.

## Обслуживание

На сервере:

```sh
systemctl status groundandlaw
journalctl -u groundandlaw -n 50 --no-pager
systemctl restart groundandlaw
nginx -t
curl http://127.0.0.1:8080/api/legal-help/config
```

После обновления кода нужно перезапустить службу. Изменение nginx сначала
проверить `nginx -t`, затем `systemctl reload nginx`.

## Следующий этап: HTTPS

Подключить домен A-записью к IP, получить сертификат и настроить HTTPS.
В nginx изменить `server_name` и точное соответствие в `map`: внешний HTTPS
Origin должен преобразовываться в локальный Origin только для своего домена.
Чужие Origin сохраняются и отклоняются приложением. Не заменять Origin
безусловно: это отключит проверку запросов с чужих сайтов.

После HTTPS установить requirements-speech.txt, загрузить модель в
`app/data/speech-model`, указать `SPEECH_PYTHON=/opt/groundandlaw/venv/bin/python`
и снять `SPEECH_DISABLED`. Проверить распознавание реальной записи.

Сейчас стенд доступен без авторизации по ссылке; лимит запросов не заменяет
авторизацию. Перед широким распространением нужна защита доступа и отдельная
проверка нагрузки. Существующие ограничения и таймауты внешнего LLM сохраняются.
